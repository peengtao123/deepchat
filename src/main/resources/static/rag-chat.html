什么是 RAG？

RAG (Retrieval-Augmented Generation) 检索增强生成，结合了信息检索和文本生成技术。

  • 检索：从知识库中查找相关文档
  • 增强：将检索结果与问题结合
  • 生成：基于上下文生成准确回答

API 端点

  • POST /api/rag/document/add - 添加文档
  • GET /api/rag/search?query=xxx - 搜索文档
  • POST /api/rag/chat - RAG问答
  • POST /api/rag/chat/stream - 流式问答
