# 多轮对话功能 - 快速开始

## 🚀 5分钟快速体验

### 1. 启动应用

```bash
# 在项目根目录执行
mvn spring-boot:run
```

等待应用启动完成，看到以下日志表示成功：
```
Started DemoApplication in X.XXX seconds
```

### 2. 访问聊天页面

打开浏览器访问：
```
http://localhost:8080/spring-ai-chat.html
```

### 3. 测试多轮对话

#### 第一步：介绍自己
在聊天框输入：
```
我叫张三，今年25岁，是一名软件工程师
```

点击发送，AI 会回复问候信息。

#### 第二步：测试记忆
继续输入：
```
我叫什么名字？我多大了？我的职业是什么？
```

AI 应该能正确回答：
- 你叫张三
- 你今年25岁
- 你是软件工程师

✅ 这说明记忆功能正常工作！

#### 第三步：更多上下文测试
继续输入：
```
推荐一本适合我的编程书籍
```

然后问：
```
这本书的作者是谁？
```

AI 应该能理解"这本书"指的是上一轮推荐的书籍。

### 4. 使用会话管理功能

#### 清除记忆
1. 点击底部的"清除记忆"按钮
2. AI 会显示"✅ 会话记忆已清除"
3. 再问"我叫什么名字？"
4. AI 应该不记得了（因为记忆已清除）

#### 创建新会话
1. 点击底部的"新会话"按钮
2. 会话ID会更新
3. 对话界面清空
4. 可以开始全新的对话

### 5. 禁用记忆功能（对比测试）

1. 取消勾选"启用多轮对话记忆"
2. 输入"我叫李四"
3. 再问"我叫什么名字？"
4. AI 应该不记得（因为禁用了记忆）
5. 重新勾选"启用多轮对话记忆"恢复功能

## 🔧 高级用法

### 使用系统提示 + 记忆

1. 勾选"显示系统提示设置"
2. 输入系统提示，例如：
   ```
   你是一个专业的Java编程专家，擅长解答技术问题
   ```
3. 开始对话，AI 会以Java专家的身份回答
4. 记忆功能仍然有效，可以记住对话上下文

### 流式响应 + 记忆

1. 确保勾选"启用流式响应"
2. 确保勾选"启用多轮对话记忆"
3. 发送消息，AI 的回复会逐字显示
4. 同时保持对话上下文

## ❓ 常见问题

### Q1: 刷新页面后会话ID会变吗？
A: 不会。会话ID保存在浏览器 localStorage 中，刷新后保持不变。

### Q2: 关闭浏览器后再打开，会话还在吗？
A: 会话ID还在，但如果你清除了浏览器数据或使用隐私模式，会生成新的会话ID。

### Q3: 如何完全重置？
A: 点击"新会话"按钮，或者在浏览器控制台执行：
```javascript
localStorage.removeItem('chat_session_id');
location.reload();
```

### Q4: 记忆功能会影响性能吗？
A: 对于正常长度的对话（几十轮），影响微乎其微。如果对话非常长（几百轮），可能会稍有延迟。

### Q5: 重启应用后记忆还在吗？
A: 不在。当前使用内存存储，应用重启后所有记忆都会丢失。如需持久化，需要实现基于数据库或Redis的存储。
