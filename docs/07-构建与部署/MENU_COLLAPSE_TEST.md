## 🔍 调试方法

如果功能没有正常工作：

### 检查浏览器控制台

按 F12 打开开发者工具，查看 Console 标签：

**正常情况应该看到：**
```
当前页面: README.html
展开活动菜单: 概览
菜单折叠初始化完成
```

**如果没有看到这些日志：**
1. 检查是否正确加载了 menu-collapse.js
   - 在 Network 标签中查找 `menu-collapse.js`
   - 状态应该是 200 OK

2. 检查 jQuery 是否可用
   - 在 Console 中输入 `$` 或 `jQuery`
   - 应该返回一个函数

### 检查文件是否存在

确认以下文件存在：
```
target/site/js/menu-collapse.js
target/site/js/apache-maven-fluido-2.0.0-M9.min.js
```

### 检查 HTML 引用

在浏览器中右键查看页面源代码，确认 head 部分包含：
```html
<script src="./js/apache-maven-fluido-2.0.0-M9.min.js"></script>
<script src="./js/menu-collapse.js"></script>
```

（子目录中的文件使用 `../js/`）

## ⚠️ 常见问题

### 问题1：菜单没有折叠

**可能原因：**
- JavaScript 文件未加载
- jQuery 冲突

**解决方法：**
- 检查浏览器控制台的错误信息
- 确认 file:// 协议可能导致跨域问题，建议使用本地服务器

### 问题2：所有菜单都展开了

**可能原因：**
- 当前页面检测失败
- 菜单项的 href 与当前页面不匹配

**解决方法：**
- 在控制台输入 `window.location.pathname` 查看当前路径
- 检查菜单项的 href 属性是否包含该路径

### 问题3：点击菜单没有反应

**可能原因：**
- 点击事件未绑定
- CSS 选择器不匹配

**解决方法：**
- 在控制台运行 `$('.nav-list li.nav-header').length` 查看是否找到菜单项
- 应该返回大于 0 的数字
